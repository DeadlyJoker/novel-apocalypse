# 第一章：手术费

血是黑的。

林深见过太多血，知道在霓虹灯底下什么颜色都会被吃掉。巷口那根歪斜的灯管每隔三秒闪一次紫光，落在地上的血泊里就跟泼了墨似的。

他戴好黑色医用口罩，单膝跪在铁架床边，手里的手术刀换成了改锥。

患者是个三十出头的男人，左上臂的义体接口处皮肤已经烂出一圈黑紫色的溃烂，黄白色的脓液顺着胳膊往下淌，跟机油混在一起。整个诊所弥漫着一股甜腻的腐臭味——那是组织坏死和劣质润滑剂搅和在一起的味道。

「怎么搞的？」林深问。

「装的二手件。」患者咬着牙，额头上全是汗，「南城老周那儿拿的货，说是翻新件，装上第三天就开始发痒，今天直接动不了了。」

林深没接话。翻新件，说得好听。地下区哪有翻新件，都是死人身上拆下来的报废货，拿稀盐酸泡一泡，磨掉锈，换个外壳就当新的卖。他见过更惨的——装上去第三天整条胳膊带电，差点把人电死。

「忍着。」

他用改锥撬开接口盖板，一股黑烟冒出来。里面已经烧得一塌糊涂，线路板粘连在一坨焦糊的塑料上，对接端口的针脚断了两根，剩下的歪歪扭扭地杵着。

林深皱了下眉。这比他想的还严重。

他转身走到工作台前，那台生了锈的二手手术灯晃了两下，灯光在墙上投出一个歪斜的光圈。墙上钉满了架子，上面堆着各种零件——生锈的液压管、拆了线的电机、半罐没标签的冷却液。墙角纸箱里堆着几根废旧的机械手指，断电后无力地卷曲着，像死掉的蜘蛛腿。

他在零件堆里翻了半天，找到一块还算干净的对接主板。那是上个月从废品站淘来的，花了他三十块，上面还贴着编号标签——2043年产，旧型号，性能孱弱，但至少没烧过。

又找了根配套的液压软管，摸了摸内壁，没有破损。再把剩下那半瓶医用级冷却液从柜子里拿出来——这是他诊所最值钱的东西了，一瓶要八十块，平时舍不得用。

回到铁架床边，患者已经把上衣脱了，露出精瘦的躯干，锁骨下方有一块模糊的纹身——一条蛇，盘在一个骷髅头上，蛇牙清晰可见。

林深瞥了一眼，没说什么。蛇牙会。地下区的帮派之一，干的是义体走私和器官买卖。他以前接触过他们的外围成员，没什么好印象。

「打麻醉吗？」患者问。

「打麻醉加一百。」

「那算了。」

林深没再废话。他拿起消毒喷壶，对着溃烂的伤口就是一阵猛喷。双氧水碰上烂肉会起白沫，滋滋地冒泡，顺着手臂往下淌，滴在铁架床的缝隙里。

患者浑身绷紧，牙关咬得咯吱响，愣是没吭声。

清洗、清创、剥离坏死组织。林深的手很稳，那把手术刀在他手里像长了眼睛，每一刀都干净利落。刀尖挑开粘连的薄膜，把烧焦的线路板和皮肉剥离，换上新主板，重新接好液压管，灌入冷却液。

缝合的时候他没用心皮缝合器——那东西太贵了，用一次就要换一个针头。他直接用的普通缝合针线，粗黑线，缝出来的针脚密密实实，跟补鞋似的。

「动一下。」

患者活动了一下手指，又握了握拳。义体重新通电后发出细微的嗡鸣声，液压管在工作时会有规律地收缩舒张，像呼吸一样。他长出一口气，整个人软在床上。

林深摘下手套扔进垃圾桶，走到水槽边洗手。冷水冲掉手上的血迹和油污，水流顺着指缝流进下水道，发出咕噜咕噜的声音。水槽边沿积了一层黄褐色的水垢，上面搁着半块肥皂。

「多少钱？」患者问。

「主板八十，液压管三十五，冷却液用了三分之一算你三十，手术费一百五。一共两百九十五。」

患者从裤兜里摸出一卷皱巴巴的现金，数了两百九十五块放在桌上。林深擦了擦手走过去，拿起钱一看，眉头就皱起来了。

「这钱不对。」

「怎么不对？」

林深把其中一张一百块举到灯光下。水印模糊，纸张手感过于光滑，金属线位置明显偏了。他又看了看另外两张，全是同一个问题。

「假币。」他把钱扔回桌上，「换真钱。」

患者的脸色变了，声音也沉下来：「兄弟，我这只有这些。」

「那你去ATM取。」

「我要能取钱还找你做黑市手术？」

林深盯着他，对方也毫不示弱地瞪回来。两人之间隔着那张破旧的手术台，桌上那把改锥还带着刚才撬盖板留下的油污。

诊所里的空气凝固了几秒。通风管里传来嗡嗡的震动声，是楼下那家奶茶店的排风扇在转。天花板上的灯管忽明忽暗地闪了两下，像要熄了又续上了电。

林深深吸一口气，把假币收进口袋。

「走吧。」

这个月第三次了。他告诉自己下次先验钱再做手术，但他也知道这没用。地下区的人有几个用得是真钱？能拿出假币的已经算有良心了，至少没拔刀。

患者有些意外，看了他一眼，快速穿好衣服往外走。走出门口时顿了顿，低声说了句：「谢了。」

林深没应声。

门关上，诊所又只剩下他一个人。墙上那台老旧的时钟指到凌晨一点二十三分。窗外是永夜，霓虹灯的光透过积灰的玻璃窗照进来，在地上投出红色的光斑。

他靠着墙站了一会儿，感到左臂隐隐作痛。

卷起袖管，哑光黑的装甲面板上多了几道划痕，暗红色的液压管在缝隙间透出微弱的光。他活动了一下手指，义体关节发出轻微的咔咔声——快该换润滑油了。

一周前跟人打架弄的。有个混混带着人来砸诊所，说是他治死的患者家属。林深把人打了出去，左臂也被铁棍砸了两下。不是什么大事，装甲面板扛得住，但关节连接处有损耗，不保养早晚出问题。

他自己的保养一直随便糊弄，能省则省。省下来的钱都给了妹妹。

想到林小满，他收拾桌子的动作顿了顿。

今天一整天没接到学校电话。没有电话就是好消息，说明她没晕倒。前两天她又在课堂上昏了一次，老师打电话说建议休学，被他顶了回去。休学？休学在家他更不放心，至少学校有人看着。

他把桌上的工具收拾好，手术刀拿去泡消毒液，改锥、扳手、钳子按大小码好。每次做完手术他都会把工具清理一遍——这个习惯跟手艺无关，纯粹是因为穷。工具坏了就得买新的，而他买不起。

门口传来脚步声。

林深抬起头，这个点还有患者？他看了一眼墙上的钟，凌晨一点半。地下区的诊所没有固定营业时间，只有一条规矩：门开着就进来。

但脚步声不对劲。太轻了，不是成年人的脚步。

门被推开，一个瘦小的身影站在门口。

林小满穿着宽大的校服外套，整个人裹在里面显得更小了。她脸色苍白得不像话，嘴唇毫无血色，那双被改装护目镜遮住的眼睛下方有明显的青黑色。

她扶着门框，胸口起伏着，呼吸急促而轻浅。

「哥……」

林深的心里咯噔一下，扔下手里的扳手就走过去。

「怎么了？」

「我又晕倒了。」林小满抬起头，声音很小，像是在说一件微不足道的事，「放学的时候，在校门口。老师让我在医务室躺了一会儿，我没事了才回来的。」

她说着没事，但抓住门框的手在发抖，指节泛白。林深一把扶住她，感觉到她胳膊冰凉，整个人轻飘飘的，好像一阵风就能吹走。

「吃饭了没？」

「吃了。学校食堂的。」

「吃的什么？」

「饭。」

林深知道她在说谎。她每次昏迷醒来后都吃不下东西，但他没有拆穿。他把她扶到诊所里唯一一张完整的椅子上坐下，转身去给她倒水。

暖壶里的水是上午烧的，已经温了。他倒了一杯端过来，蹲在她面前看着她的眼睛。

「什么时候开始的？」

「就放学。突然眼前一黑，醒来就在医务室了。」林小满接过水杯喝了一口，捧着杯子的手还在轻微地颤抖，「医生说让我去医院做检查。」

林深没说话。

医院。做检查。这三个字在地下区等于无底洞。正规医院的神经科挂号费就要三百，做一次核磁共振两千起步，开颅手术的费用更是天文数字。

而在黑市诊所，一次神经系统的脉冲干涉治疗只要五百，能顶着走两三个月。副作用是越来越严重，病程会加速恶化。

他已经选了后者。

因为他没有选择。

「哥知道。」林深站起来，伸手揉了揉她的头发，「明天哥带你去老周那儿做个检查，看看现在到什么程度了。」

「又要花钱。」

「没事。」

林小满把杯子放下，抬头看着她哥。诊所昏暗的灯光下，林深脸上没什么表情，但那双眼睛里的东西她看得懂——是疲惫，是担忧，还有从不肯在她面前示弱的倔强。

「哥，要不别治了。」她的声音很轻，像在说一件跟自己无关的事，「反正也治不好。」

林深手上倒水的动作停了半秒，像个不易察觉的卡顿。然后他把杯子放回桌上，转身看着她，语气没有任何商量的余地。

「我说了，我来。」

林小满低下头，护目镜挡住了她的表情。过了好一会儿，她轻轻嗯了一声。

窗外，地下区的霓虹灯依旧不知疲倦地亮着。远处传来警笛声，断断续续，像某种钝器击打铁皮发出的声音。楼下奶茶店的排风扇终于停了，取而代之的是水管里细微的水流声。

永夜里的新天城，又开始了一个普通的夜晚。

林深把诊所的灯关了，只留了一盏走廊灯。他扶着妹妹走进后面狭小的房间，那间不到十平米的屋子塞了两张床，中间只隔着一个衣柜。

林小满躺下后很快就睡着了，呼吸逐渐平稳。

林深坐在床边，借着走廊透进来的微光看着妹妹的脸。她睡着的时候眉头也微微皱着，像是连梦境里都在忍受着什么。

他轻轻拉开抽屉，里面躺着那三张假币。

两百九十五。

他记得这笔账。

蛇牙会的账。
